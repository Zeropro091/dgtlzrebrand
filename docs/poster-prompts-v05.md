USAGE NOTES
===========================================================

1. aspect ratios: hero=2:3 (IG portrait 4:5 crop ok), services=3:2, manifesto=1:1, team=2:3
2. Midjourney: append --v 6.1 --style raw --s 50 (low stylize keeps type accurate)
3. Flux/Imagen: remove "--ar/--style raw" flags, state "vertical 2:3 aspect ratio" in words
4. TEXT ACCURACY: image models mangle small text. If text comes out garbled,
   regenerate with "(all text crisp and legible)" emphasis or fix text in Figma/Canva after.
   Best workflow: generate artwork WITHOUT text regions → overlay real text in Canva.
5. Color lock: if model drifts off Klein Blue, prepend: "exactly one accent color used:
   International Klein Blue #0B17EF on off-white #F4F4F2, no other hues"
6. Consistency across series: always reuse the [MASTER STYLE] sentence verbatim.
